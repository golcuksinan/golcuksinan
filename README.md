# Hi, I'm Sinan 👋

Pre-service English teacher (Pamukkale University, ELT, graduating June 2027).
I also build software, mostly local LLMs, Turkish speech and language tools, and web platforms for students.

### Projects
- **[Kürsü](https://github.com/golcuksinan/K-rs-)**: anonymous course and lecturer review platform for students.
  React, FastAPI, PostgreSQL, with AI moderation of comments (Hugging Face `toxic-bert`). Built in a 3-person team.
  [Live demo](https://kursu.live).
- **[Mayen v1](https://github.com/golcuksinan/mayen-v1)**: a local assistant that takes Turkish text and answers in
  spoken English, with an evaluation harness for its prompts and tool calls (archived; v2 in design).
- **[DAKIK](https://github.com/golcuksinan/dakik)**: absence tracker for Turkish university students (Django), currently being rebuilt.
- **[Crypter](https://github.com/golcuksinan/Crypter)**: command-line file and folder encryption (Fernet, parallel, chunk-safe).
